# Cloud Data Redundancy System

## Objective
This project identifies redundant and false-positive records before storing data in the cloud database.

## Features
- Duplicate Detection
- False Positive Detection
- Data Validation
- Add Records
- Search Records
- Update Records
- Delete Records
- View Records
- CSV Upload
- Report Generation

## Technologies Used
- Python
- SQLite
- Streamlit
- Pandas
- FuzzyWuzzy

## How to Run

1. Install packages

py -m pip install -r requirements.txt

2. Create Database

py database.py

3. Run Application

py main.py
